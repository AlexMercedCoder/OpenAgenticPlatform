# OpenAgenticPlatform.com

A vendor-neutral reference site for composing agentic AI from open data foundations, model choice, interchangeable harnesses and brokers, and portable standards.

## Development

```bash
npm install
npm run dev
npm run lint
npm run build
```

The static-first site uses the OpenAI Sites/Vinext scaffold. It includes JSON-LD, full sharing and crawler metadata, sitemap and robots routes, `llms.txt`, and read-only WebMCP tools. The complete phase-one product definition lives in `PRD.md`.
